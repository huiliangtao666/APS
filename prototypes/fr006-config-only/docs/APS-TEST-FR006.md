# APS-Test 用例约定：FR-006 配置与 CSV 导入

本约定用于独立副本的 UAT/验收；仅覆盖配置 CRUD 与导入校验。测试结果不能证明工装排程约束已实现。

## 准备

1. 使用 `sample-data/FR-006/18_工装配置.csv`。
2. 在“数据与 CSV”选择“工装配置（仅配置）”。首次进入有两条虚构示例数据。
3. 全部检查只在 `aps-fr006-foundation` 副本执行，不绑定或覆盖 `aps-r1` 预览。

## 用例约定

| ID | 操作 / 输入 | 预期 |
|---|---|---|
| F006-CFG-01 | 查询 `MOLD-40` | 只显示编码匹配行；行数显示过滤数/总数 |
| F006-CFG-02 | 编辑工装名称，刷新独立副本 | 新名称由本副本 localStorage 保留；R1 数据不受影响 |
| F006-CFG-03 | 新增一行，填写完整有效值；导出 CSV | 行可编辑，导出包含字段表头和新增记录 |
| F006-CFG-04 | 选中并删除一行 | 当前表删除该行；切换表时其他配置不变 |
| F006-CSV-01 | 导入示例 CSV | 两行导入，替换当前工装表，页面提示导入数 |
| F006-CSV-02 | 删除必需表头“可用数量”后导入 | 报缺失字段，不覆盖原表 |
| F006-CSV-03 | 将一个“可用数量”改为 0、负数或小数后导入 | 报行号与字段；整批拒绝，原表不变 |
| F006-CSV-04 | 重复“工装编码” | 报重复编码及行号；整批拒绝 |
| F006-CSV-05 | 清空适用任务或工装名称 | 报必填错误；整批拒绝 |
| F006-CSV-06 | 将提前占用分钟设为 -1 / 小数，或后延归还分钟留空 | 报非负整数错误；整批拒绝 |
| F006-CSV-07 | 将是否启用设为“未知” | 报允许值错误；整批拒绝 |
| F006-SAFE-01 | 导入有效记录并运行 R2.1 计算 | 工装配置不改变排程任务时间/机器；界面明确显示“未启用 / 未检查” |
| F006-SAFE-02 | 删除所有工装记录后查看/运行 R2.1 | 显示未配置/未检查语义；不得宣称工装资源校验通过 |
| F006-SAFE-03 | 查看 `aps-r1` 预览/UAT-02 数据 | 此副本提交不改变当前绑定、数据或页面 |
