# 五类排程图表字段分列

用户要求：2026-11-03，设备甘特、需求交付、设备负荷、人员工装、物料风险按字段分列，通过“显示栏位”灵活选择。

## 实现

| 视图 | 独立字段 |
| --- | --- |
| 设备甘特 | 设备编号、设备名称、设备组、真实任务数、WIP保留数 |
| 需求交付 | 需求编号、成品编号、成品名称、需求数量、单位、交付状态、真实任务数 |
| 设备负荷 | 设备编号、设备名称、设备组、窗口占用率、任务数 |
| 人员工装 | 资源编号、资源名称、资源类别、单位、可用数量、任务数 |
| 物料风险 | 记录编号、物料编号、物料名称、记录类型、本记录数量、单位、需求/在制 |

每个字段使用独立表头和单元格，共用列宽，隐藏时表头与内容一起收起。编号保留并在横向滚动时固定，名称等字段可隐藏；过长内容可悬停查看。各视图单独保存浏览器偏好，刷新保留；兼容旧版复合栏位设置。设备负荷/人员工装的逐日指标仍由原口径选择，隐藏左侧信息不删除逐日数值。栏位菜单悬浮显示，不撑高图表，沿用单菜单展开、点击外部关闭、Escape关闭行为。

只修改展示，不修改排程算法、导入数据、配置、运行、结果和指标计算。空值显示“—”，不替换为零或推断物料。
