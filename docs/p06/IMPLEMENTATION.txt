Joint scheduling
Machine interval, complete tool occupancy (including before/after offsets), each
personnel phase and all directed skill/shift/group/physical-pool constraints must
fit at the same candidate. Candidate failures leave no resource/material usage;
a later legal boundary causes the entire existing R01/R02 preview to run again.
Personnel overlapping max-demand segmentation cannot implicitly hand a complete
phase to a different group: every original phase requires continuously assigned
headcount from the same group(s). Independent roles still add, and physical pool
capacity still limits all groups jointly. This does not model individual workers.

The existing 1000-candidate and 256-phase/50000-search-step limits remain.
Failure/limit means this bounded search did not find an assignment, not global
infeasibility. Timing reasons retain source configuration/candidate/retry chain.
Ordinary plan CSV includes the frozen P06 contract, reservations and retry cause;
zero-task CSV still includes unscheduled reasons. Source frozen inputs are
available through /runs/:id/inputs, not reconstructed from current configuration.
