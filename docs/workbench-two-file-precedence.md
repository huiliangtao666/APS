## 使用和来源

先选择业务 Excel 建立数据集，再在同一数据集预览参数 Excel。参数卡主选择是“导入并采用可用参数（第二份优先）”，仍需确认才提交；另可明确仅存候选。候选文件与未支持参数持续显示未参与排程，上传本身不改变输入。两原件分别保留文件 hash，不修改原件、不将客户原件新增到公开 Git。

同一数据集维护 B、P、EDIT 三个来源层；B 主数据/业务仍由第一份维护，P 不复制需求、库存、在途、WIP。语义身份包含受控 CP/原子字段、业务对象类型/ID、单位维度、profile、scope；PA 为来源身份。单位只允许既有受控量纲与明确的 kg/千克等同义拼写，不按显示名称猜转换。按运行开始日的半开有效区间解析，层次为数据集内 EDIT > P > B，其上保留显式私有 trial 覆盖；未涉及的 B 值继续有效。不同来源可重叠，同源同义区间冲突原子拒绝。新 P 修订按区间替代已有 P，保留区间外来源，PA 及原区间可追溯。

B 重导替代业务表及 B 层，保留 P、在线参数 EDIT、试算和独立映射，不再整包保留旧 B 参数。预览按来源/区间列实际变化。在线参数保存不改 B/P 原值，统一页和步骤页使用相同 API，版本变化使 ready 过期。重导 P 预览并列 B、原 P、当前在线值、新 P 及区间；默认为保留在线值，可显式选择替代匹配区间的 EDIT。该选择、三方摘要、源 hash、版本、模式及快照均绑定预览指纹与幂等键。取消无写入。批量 trial 仍不开放。

## 日历、定义及不完整资料

原件 CAL 对象明确为工厂日历，标准班次/周日班次映射到现有实际日历表。标准班次必须大于 0，周日可为 0；实际班次与日产能分子同步，标准班次作为分母，真实生产容量与独立复核均读取这些值，并与 TM 班组窗口取交集。没有新建假 TM/CAL 占位行，不要求删除 PA3427/3428。其他未知对象保留待映射。

P 的中文业务定义、对象范围、类型说明、上下限、条件和建议展示为顶层解释；技术 CP、页签、步骤路由、只读/不可执行约束仍受控。已映射原子字段执行数值类型、整数、量纲、技术边界及 P 明确数值上下限；其余文字规则显示待编译/未支持，不执行上传公式。CP018 保留 P 的派生说明和来源只读。CP080 路线派生建议没有被当作算法；该 P 字面来源标待补，不回退 B 冒充解决。用户可显式维护已支持的字面值作为 EDIT；新增派生算法不在本次。

导入保存检查与运行检查分层。损坏结构、数字类型/单位非法、公式、同源重复/区间冲突及可判定关系错误仍拒绝整批有效提交。合法未映射、明确缺值/暂停采用可保存；明确缺值 P 是阻断标记，运行时不会退回 B，缺值不会生成 NaN 派生值或被当作 0。候选/未启用随机情景可待补。资料保存不是运行就绪。

## 本次依赖与冻结

选定需求/日窗扩展实际 BOM、路线、供货关系、所有相关物料库存/在途/采用草稿、候选设备、工装池、班组、共享库位占用，以及共享资源或物料的原已开工 WIP；递归扩展 WIP 剩余路线/待投料。就绪、计算和独立复核使用同一依赖投影。供给按原批次/订单行身份仅保留一份，不因选小范围复制余额。范围外专用制造路线缺项不阻本次；全库完整性列表仍可查询。所有相关已开工 WIP 的物理占用先保留，续排失败不释放历史锁定；独立复核同查设备、工装和人员锁定冲突。

本范围必要原子事实缺失仍阻断；没有猜测时长、质量、无限资源或供给。G01 为单线映射、G02 为制造/半成品路线、G03 为投料/物理池/WIP 剩余业务映射；实际入口是既有 A2 映射、工艺路线/业务记录和同源参数编辑，不把它们统一解释成 P 缺值。未支持能力依旧具名拒绝，不伪造维护链接。

新运行冻结全输入、B/P 文件指纹、来源策略/目录/层指纹、开始日有效参数、overlay、选择、映射和依赖清单。结果仍绑定原完整参数/映射 hash，依赖投影不替换来源指纹；历史 run/计划不补写。参数 CSV 保留逐层来源；可重导 Excel 按语义/有效期输出不重叠采用段，单独保留原 PA、来源层/hash，使用 P 的业务定义。冻结查询、重开和原 run 导出继续读取原冻结对象。
