实现与复用
提供订单计划、任务计划、资源占用、物料需求、未排原因、方案差异六类查询与 UTF-8 BOM CSV。
新增查询入口 GET /reports；导出复用 POST /export 的 stored membership、export grant、CSRF、原因与审计链路。
复用 FR032 resourceLoad、历史 queryData/timetable、comparePlans，不另建导出权限或模拟计算系统。
服务端共享报表对象生成 UI 精确记录及 CSV，viewId 为完整报表内容哈希；导出重新核验查询与保存快照，过期或扩大范围返回409。
页面显示中文数量/时间/状态摘要，保存的完整原始记录可展开，精确数量、单位、日期和溯源可查看。
元数据包含产线、方案、run、输入版本、snapshot、确认标识、保存日期、UTC+08:00、时间原点、模拟与非当前事实说明。
历史原始输入/运行/确认副本损坏时拒绝；当前输入修改不重写保存计划与已确认报表。
CSV 使用 CRLF、双引号转义、公式前缀防护；保留保存数量及精确分数，未知与条件说明不转为通过。
