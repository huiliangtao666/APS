# APS UI/UX规范 V2.1

2026.11.07；本文件由V2.1第10章派生，来源与范围以[完整说明](../requirements/revisions/APS-V2.1-20261107/requirements-design.md)为准。

## 10 UI/UX设计规范：页面、流程、交互与视觉风格

本章保留V2页面/查询/图形规范，并以#155—169的后续要求更新插单、多方案、主计划及物料维护。最新布局和流程覆盖同问题旧描述，原始要求仍在V2历史版追溯。12px常规字号/28px控件等已确认要求保留；没有用户唯一数值的视觉尺度继续标“规范建议”，不冒称最新本地CSS已逐像素核验。

### 10.1 信息架构和页面分工

| 页面/入口 | 主要职责 | 进入与返回 |
| --- | --- | --- |
| 排程流程 | A1数据准备→A2就绪补缺→A3本次配置→A4计算→A5核对→A6保存导出。 | 路标显示当前位置、前提和阻塞；返回不丢范围和草稿。 |
| 业务数据查询与维护 | 五类查询18子视图，查询汇总/明细并按真实来源进入维护。 | 合并旧业务原表入口；移除独立“业务数据”“工装配置”重复页。 |
| 配置参数查询与维护 | P基线、当前采用值、对象矩阵/日历、同源维护及日志。 | 步骤关键参数与统一页同效，保存后回原步骤并提示重查。 |
| 排程结果 | 顶部选择已保存run，紧凑指标及错误/提醒入口，下分六视图。 | 替代旧“排程结果与六视图”长标题；无结果给选择/创建指引。 |
| 生产主计划报表 | 物料总览＋单物料日矩阵＋单据/批次/来源明细。 | 独立报表CR入口；未实现/未开放时明确状态，不假可点。 |
| 插单 | 抬头独立入口，五步单页、四态/完成比例、受控重导、策略重排、九项指标及来源。 | 基准与候选分开，五步收起不丢内容，快捷入口同状态。详见10.10。 |
| 多方案试算比较 | 同底本情景、按天条件、批量试算、并列指标、差异追溯及显式采用。 | 情景名称可辨识，反馈明确；试算不改共享事实。详见10.11。 |
| 每日数据模拟器 | 独立场景、规则/脚本、日推进、日结、检查点及兼容导出。 | 独立调试/联动状态清楚，不默认写主程序。 |

### 10.2 完整用户旅程及反馈

| 动作 | 即时反馈 | 异常与恢复 |
| --- | --- | --- |
| 选择文件 | 显示文件名/类型，按钮称“上传并预览”。 | 未上传不报已成功；禁用按钮就近给原因。 |
| 预览/整批确认 | 显示影响范围、具体异常及“尚未提交”；确认后显示成功版本/基线。 | 超时提供查上次结果，原数据不部分变更。 |
| 维护参数/业务 | 当前值、适用对象/日期及修改草稿清楚；保存/取消明确。 | 冲突保留输入并对比最新值，取消不写入。 |
| 范围检查 | 当前检查状态与关键缺项可定位。 | 数据/P修订/求解器/日窗改动立即标旧检查失效。 |
| 生成计划 | 显示真实排队/阶段、耗时、可取消状态。 | 不估算假百分比，不拿超时当业务无解。 |
| 核对结果 | 先看指标、点击数字到同范围问题，再看图与来源。 | 未知/部分/无任务分别显示，不把已排写已完成。 |
| 调整/插单/试算 | 展示基准与变更影响、新运行及采用状态。 | 保护已执行/完成/锁定；已开工净剩余按明确策略调整；失败保留原计划。 |
| 保存重开/导出 | 重开同一run和冻结条件，导出范围/单位/格式明确。 | 无真实维护入口标未接入，不造链接。 |

### 10.3 通用筛选、栏位与分页

- 选项多的筛选框内搜索并多选，初始和重置实际全选当前版本范围内全量候选；不是仅第一页打勾。搜索保留隐藏已选，同字段并集、跨字段交集；清空产生空结果，恢复全选有明确动作。
- 同一时刻只展开一个下拉；打开另一项、点击外部或Esc收起，选择不丢。弹层不撑高结果区、不被滚动容器裁掉，查询/重置位于操作带固定可达位置。
- 每个表和图形视图都有独立“显示栏位”，表头和数据同步隐藏，偏好分别记忆并兼容旧组合栏位。必要标识可固定；隐藏不删数据或日期图。
- 通用默认每页100，可选200/500；物料/BOM维护页按#169专用规则默认全部，可选25/50/100。先全量筛选、稳定排序、计数/汇总后分页，条件变更回第一页。完整筛选导出不是当前一页；候选分页不能把全选缩成一页。
- 有物料筛选的适用页支持“根据BOM显示”；开启按有效版本/日向下递归、多根并集与共享子件展示去重，关闭只看所选层，不按编码猜关系，不改变需求/分配。
- 移除的或不适用的筛选不得留在缓存中暗中生效；不同子页切换要显示真实当前条件，不共享一套错误筛选。

### 10.4 字体、尺寸和间距

| 项目 | 明确规范值 | 依据/性质 |
| --- | --- | --- |
| 常规控件、表格与筛选 | 12px；行高建议1.4（约17px）。 | 12px来自#94；行高为V2规范建议。 |
| 辅助说明/单位/来源 | 11px；常规业务正文不小于12px。 | 既有CSS参照；低缩放图注例外，不以缩小关键字解决拥挤。 |
| 页面标题/区域标题 | 18px/14px，字重600；短说明同排11—12px。 | V2规范建议；同排原则#91/#100。 |
| 核心指标 | 建议20px半粗，标签11px；指标上下内边距4—6px。 | V2规范建议；#135/#145要求紧凑。 |
| 字体族 | 中文优先系统苹方/微软雅黑等无衬线，西文跟随系统；数字建议等宽数字特性。 | V2规范建议，避免多种装饰字体混用。 |
| 常规输入/下拉/按钮 | 28px高，字号12px；水平内边距7—8px。 | 28px及同排来自#94；内边距参照当前样式收敛。 |
| 控件/字段间距 | 同组4px，字段组间6—8px，区块间8—12px，页面边距12—16px。 | V2规范建议，使用2/4/6/8/12/16px尺度。 |
| 结果表 | 建议26—28px行高，单元格上下4px、左右8px；表头28px。 | V2规范建议；多行内容进详情，不任意撑高所有行。 |
| 图形行与任务条 | 默认行高28px、任务条18px；紧凑24px、舒适36px可选。 | V2规范建议；保留一屏总览及内容区滚动。 |
| 固定顶部导航 | 现有52px作为参照；标题/筛选结果行合并，避免多个空白抬头。 | 当前InputData样式参照，#100/#145布局裁决。 |
| 参数说明按钮 | 15px圆形“!”，字段标题旁一处；支持悬停/点击/聚焦，Esc关闭。 | #120/#122及参数帮助记录。 |
| 圆角/边框 | 建议4px圆角、1px细边框；卡片层次最多页面区＋结果区，避免卡片套卡片。 | V2规范建议；紧凑嵌套原则#84—92。 |

这些px用于应用视觉，不是Word正文排版单位。优先保持“能一行不多行、能一个单元格不拆格”，但不能截掉关键单位、状态或误把业务字段合并：五图表中的编号、名称、数量、单位按独立列展现，与#143分列要求兼容。

依据：[#89](https://github.com/huiliangtao666/APS/issues/89)、[#91](https://github.com/huiliangtao666/APS/issues/91)、[#92](https://github.com/huiliangtao666/APS/issues/92)、[#94](https://github.com/huiliangtao666/APS/issues/94)、[#143](https://github.com/huiliangtao666/APS/issues/143)

### 10.5 色彩、图标与紧凑布局

| 用途 | V2视觉规范 | 语义限制 |
| --- | --- | --- |
| 主文字/次文字 | #243448 / #64748B；背景白色或#F6FAFC，边框#DCE2E9。 | 规范建议，参照现有样式；来源说明不能低对比到看不清。 |
| 主要操作/选中 | #194E77主操作，#087E83关联/选中。 | 规范建议；只给当前最重要的动作主色。 |
| 错误/风险/未知/正常 | #C0362C红、#B56B10橙金、#64748B灰、#22724B绿。 | 色值为建议；必须带短文字/图标，不靠红绿独自表达。 |
| 可点击指标 | 数字下划线＋按钮语义，悬停/聚焦可辨识。 | 只打开该指标对应口径记录；不可点击数值不加假链接。 |
| 选中/观察日/周末 | 轻底色或细边，保持原任务状态颜色。 | 不把“已选”或“周末”误画成超占/故障。 |

页面统一结构：固定导航→标题与数据/运行选择同排→单行主筛选操作带→结果表头（总数/栏位/分页/导出）→核心表/图→按需浮窗。低频说明折叠，移除重复标题、同run长说明和无业务作用的汇总空区；来源仍在流程/明细可追。

> 紧凑布局示意：固定导航 → 标题/数据来源同排 → 单行筛选（默认全选）/查询重置 → 结果表头（数量/栏位/100-200-500分页/导出）→ 表格或甘特 → 按需详情浮窗。原HTML提供可视样例，非实际run。

图表可在内容区横向/纵向滚动，左侧标识和日期表头固定；窄区域优先横向滚动而不把筛选拆成多行，查询/重置固定可见。960px内容宽度是#145实际布局参照，不承诺任何窄屏所有条件同时可见。浮层挂在可见区域，不被sticky头部/表格裁切；不能用无限缩小字体换一屏。

| 产能 / 工艺与班组 | 路线编号/工序、设备组、班组、人数/工装及阶段工时等待。 | 去开始/结束/信息截至和不适用类别；保留成品、路线、设备组、班组及关键词。不删除制造半成品真实路线。 |
| 补料 / 采购建议 | 物料供应商、需料/下单/到货/放行、净缺口、MOQ倍数与草案状态。 | 建议/未下达明确，来源到NC/MR/BOM及参数。 |

### 10.7 排程结果：六视图与同口径问题入口

页面名称统一为“排程结果”。顶部仅保留已保存运行选择；核心指标在同一紧凑条显示，末尾为红色“错误N”和橙金色“提醒N”，带下划线可点击。移除大块输入说明、重复操作摘要，仍可在来源详情查看冻结数据和条件。

依据：[#111](https://github.com/huiliangtao666/APS/issues/111)、[#134](https://github.com/huiliangtao666/APS/issues/134)、[#135](https://github.com/huiliangtao666/APS/issues/135)、[#145](https://github.com/huiliangtao666/APS/issues/145)

| 结果视图 | 表现与字段 | 筛选及范围 |
| --- | --- | --- |
| 设备甘特 | 分钟计划显示真实分钟任务、半小时刻度；日模型按日期及检查范围，不伪造日内时刻；设备行、停机、准备/运行等真实区段；短任务保留可点区域，不伪造持续时间。 | 关键词、日期、资源/资源组；共享占用可多轨呈现。 |
| 需求交付 | 交付甘特在上、折叠明细在下；需求量、供给/完成与交期边界分别表达。 | 关键词、日期、成品/需求/状态；任务完成不冒充发运签收。 |
| 人员工装 | 资源×日期矩阵，峰值占用/可用，必要时余量；人数、套数分单位。 | 资源关键词、日期；全匹配资源和日期，不受任务分页截断。 |

错误统计包含最终未排需求记录、独立检查器问题及明确severity=error的计算记录；提醒包含预计迟交、其他计算过程记录和缺料记录。按记录计数，不悄悄按需求去重；弹窗必须使用同run、同范围和同口径明细，解释可能交叉。不能把过程拒绝候选等同最终未排，不能显示17却打开37条不同范围记录。

### 10.9 生产主计划：日矩阵、指标及浮动明细

页面沿排程结果的紧凑布局：标题/数据版本同排→筛选与查询/重置→物料总览→选定物料日矩阵→按指标打开来源。需求、库存、采购在途、主计划生产、采购补给的量和日期分开；业务单位明确，同物料下才能比较。同一数据来源范围内，每项字段/指标一处解释入口，标题有业务名称时不再重复悬停显示同名；解释应说明含义与依据。

#### 10.9.1 直接数值与缺失表达

| 数据情况 | 主表表达 | 明细解释 |
| --- | --- | --- |
| 有可取得且有来源的值 | 直接显示真实数值，0保留0；不被通用“待核对”遮住。 | 原始需求/供应及日余额逐项来源。 |
| 不适用或本报表该字段未覆盖 | 显示“-”。 | 解释不适用/未覆盖的具体原因，不当作0或有效供给。 |
| 本应必需但缺失/未知 | 明确缺项/未知状态；若矩阵占位为“-”，明细须明确缺项及受影响计算，不能混淆。 | 缺何字段、来源、哪些指标无法判定及补充入口。 |
| 当前尚未计算 | 标未计算/未生成。 | 不借用其他run或当前输入代替冻结结果。 |

可取得的逐日预计余额直接显示。基础业务等式为：期末预计余额=期初余额+本日合格可用收货+本日可用制造产出−同口径本日扣减；前日余额滚入次日。同一采购在途转收货只计一次，建议订单未接纳前不当实际供应。对需求、实发、预留的扣减口径按该指标冻结定义，不能把同一需求与领用/发运再减两次；缺定义或缺来源的高级PAB承诺仍不启用。不要因V2旧范围排除精确PAB而屏蔽已有可计算余额，也不要把后续显示余额扩成全部高级库存算法已验。

#### 10.9.2 点击与交互

每个日期×指标格点击打开**该指标专属浮动明细**：第一行一句话概括“某物料、某日期、某指标、多少量/什么状态”，随后依次为口径/公式、关键日期、冻结来源、支持清单。不再先展开一堆页签；点需求只看需求，点库存只看库存批次，点采购只看采购单行，确需关联时提供下一层明确入口。

支持在指标间切换、键盘移动/关闭，关闭回原单元格；浮窗位置不遮住全部日期矩阵，不出可视边界。明细自己的表可选栏位、筛选/分页及同范围导出；冻结run不读取当前新参数。#160记录16项指标弹窗，属于该版本来源覆盖数，不是永久硬编码只允许16项。原生XLSX导出是否接通按实际证据判断，不能改扩展名冒充格式。

依据：[#158](https://github.com/huiliangtao666/APS/issues/158)、[#159](https://github.com/huiliangtao666/APS/issues/159)、[#160](https://github.com/huiliangtao666/APS/issues/160)。

### 10.10 插单：五步单页和九项指标

“插单”是抬头栏的独立入口，进入保留数据集、业务版本、P修订、基准/候选、窗口及观察日期/时点。入口不计算不采用。当前最新页面结构按下表替代#155最初四主区域页签，不再同时要求两套布局。

| 单页顺序 | 展示与操作 | 关键反馈/保护 |
| --- | --- | --- |
| 1 当前基线任务确认 | 基准任务表、四态、完成比例、开始/截止及数量；可批量状态设置。 | 未填表单默认未开工；已保存事实优先；已开工50%等是模拟表单初始化，须确认而非自动实绩。 |
| 2 插单导入 | 文件、上传预览、整批确认同排；业务化校验信息；确认需求清单留在本区。 | 支持表头映射；同ID未采用更新先预览差异，普通/已采用/在途冻结保护。 |
| 3 待排任务清单 | 原任务净剩余与已接纳插单，标来源/任务身份/数量/状态。 | 区分实耗和已完成物料；变更后同步刷新，不用旧队列误排。 |
| 4 策略与执行排程 | 按基准粒度给观察/范围、冻结及策略；检查、运行、取消。 | 灰色不可用按钮旁明确缺什么以及可做动作；错误含字段/原因/恢复路径。 |
| 5 结果展示 | 九项可点击指标、同run六视图入口、候选保存/放弃/显式采用。 | 结果过期标需重算，失败保留基准；未达交期不被标严格已排。 |

五步初始全部展开，可独立展开/收起。折叠只隐藏显示，不卸载导致丢失输入/文件/选择；切换计划或离页处理未保存内容。每步标题短，操作行紧凑，减少重复提示和二次展开；低频策略明细可按需收起。入口不增加“讨论意见”。

#### 10.10.1 九项可点击指标

| 顺序 | 指标 | 计数和下钻要求 |
| --- | --- | --- |
| 1 | 插单总数 | 本候选冻结范围内有效插单需求条数，按需求ID去重；数字可点。 |
| 2 | 需求总数 | 本次冻结需求清单的有效需求条数，明确普通/插单组成；数字独立可点，不混工序任务数。 |
| 3 | 插单已排 | 数量完整且截止等适用条件满足的插单需求。 |
| 4 | 插单未排 | 同范围内未满足上述严格条件的插单；部分、未排、数量排满但迟交细分原因。 |
| 5 | 原任务已排 | 满足该原任务数量和截止等条件的基线工序任务；沿稳定任务身份去重。 |
| 6 | 原任务未排 | 未满足严格条件的基线任务，包括已安排但未满足交期；不能直接等同无任务。 |
| 7 | 原任务调整－已开工 | 以基准保存状态分组，实际净剩余安排有变化的原任务，列改前/改后及保护段。 |
| 8 | 原任务调整－已锁定 | 实际发生锁定任务变化的记录，不以建议解锁冒充变化；自动重排应保护锁定，无变化显示0。 |
| 9 | 原任务调整－未开工 | 未开工原任务实际变化，解释时间、资源、量及连锁影响。 |

前两项紧凑展示为“插单总数 / 需求总数”，两个数字分别能点；其余按上述顺序。计数必须标明**需求条数 vs 基线工序任务数**；不同量纲不得相加。#167未给出的需求分母特殊例外或范围规则不得隐藏推定，若冻结定义尚缺，明确待核实并保留原清单；若普通+插单均进入当前求解，需求总数按该联合有效清单解释。

每项独立浮窗：一句概括→指标定义/公式→本次窗口和冻结来源→对应清单。旧“插单处理/原需求影响/任务调整/解锁建议”的重复展开区取消，业务内容归入对应弹窗；设备甘特、批次谱系仍可从相关记录进入。实际锁定变更有明确纠正/例外来源和审计，不能在计算过程中静默解锁。

严格已排示例：需求100千克、截止11.05，安排100千克但11.06交付，此屏归“未排”，明细显示“已安排100、晚1天”。求解结果的安排量仍100；其他交付视图显示已安排/迟交，不被这组严格分类抹去。未知判定单列原因，不涂成准时。

依据：[#162—167](https://github.com/huiliangtao666/APS/issues/167)，各项原记录见第16.6节；核心业务规则见9.3。

### 10.11 多方案：同基准、日模型与过程反馈

独立抬头入口“多方案试算比较”，结构为：选择保存对比组/新建组→冻结基准摘要→维护情景条件→选定批量试算→并列指标表→差异明细→保留/放弃/采用。选择器显示情景名称，编号/修订在明细；用户无需记系统ID。

当前按天观察和生效日期，支持合格人员增加、明确日容量增加、采购预计到料日期延期；沿保存计划状态/比例/耗料/锁定。每次校验、保存、运行、取消、完成/失败有可见短反馈；错误保留输入。批量选择是用户要执行的对象，区别于只读筛选默认全选；不能因进入页面自动试算。条件只用于该情景，修改后旧结果保留并标失效。

并列表显示同一需求分母、准时/覆盖、迟交/未排/未知、已知延期、原任务变化及有依据的费用；点击到该情景同范围证据。原计划、不同情景和候选不会重复扣库存。选择偏好不等于采用，采用须显式核对和新版本记录。日模型不宣称分钟资源峰值已验，跨模式接缝沿#157。

依据：[#156](https://github.com/huiliangtao666/APS/issues/156)、[#168](https://github.com/huiliangtao666/APS/issues/168)。

### 10.12 物料/BOM维护：有效期、参考字段与重导保护

沿10.6的查询表和分层图增加同源维护：物料来源、业务类别、补货属性及基础单位按参数导入相同类型、对象范围、版本、有效期校验；保留数值参数编辑和显式生产提前期维护。每箱数量等派生关系从净重/换算来源修订再重算，不直接改派生格制造矛盾。

包装结构、安全库存模式等当前未参与计算的字段可保存参考值，但显示“未参与排程”，导出/重开仍保留原值。不能因可编辑就标已生效到求解器。每次人工/导入保留旧新值、操作者或真实可识别来源、时间、修订及有效区间；没有正式身份时不可伪造实名。未来生效编辑按其日生效，旧run不变。

重新导入**默认保留在线修改**，明确选择替换后才覆盖；预览显示将保留和将替换的范围及冲突。该规则不改变第二份P语义优先：先按同scope/单位/有效期解决合法编辑与导入冲突，P约束仍适用，不能保留非法旧值冒称成功。

本页面分页是最新专用例外：**默认全部，选项25/50/100**；覆盖本页旧100/200/500，其他查询仍用通用规则。全量物料/BOM不能被前端截断；#169样例140物料、317BOM是该数据版本核对数，不是程序上限。版本、父项/子项、生效/失效日及投料位置映射到真实字段，日期显示日历值，不再留空假列。

依据：[#169](https://github.com/huiliangtao666/APS/issues/169)。

### 10.13 主界面日/分钟切换：后续设计

主导航附近设计“日计划 / 分钟计划”同级选择；数据、计划版本、检查范围及求解器可区分。进入保存计划以该计划原粒度为准；切换未保存草稿先处理，不触发求解/采用，不重写Excel/历史run。没有另一模式结果显示未生成。

日计划展示日期与数量/日容量，明确日内未验；分钟计划甘特保真实分钟、半小时刻度。分钟run切到日报只改显示汇总，不伪造日run。日→分钟明确新候选及待补字段；跨粒度比较说明不同能力。#157仍按工程编制及各阶段证据落实，本章描述不等于当前页面已有切换按钮。

### 10.14 配置、求解器及每日模拟器
