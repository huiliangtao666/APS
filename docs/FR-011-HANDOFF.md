# FR-011 预计到料与可用时间

来源：canonical Project #2 唯一 `[FR] FR-011 预计到料与可用时间`，item `PVTI_lAHOFM9WU84BpE1czhEHgn8`，draft `DI_lAHOFM9WU84BpE1czgLhAgQ`。实现基础为 FR-010 已 push SHA `753b940cc80ee17379745dab7af57c77172f8c67`，保留 FR-002 主数据和 FR-010 库存能力。没有新建 backlog 卡或平行任务。

## 实现行为

“数据与 CSV”增加预计到料、延期模拟记录、计划供给引用三张可编辑表，支持当前表 CSV 导入/导出。预计到料维护供给编号、物料、批次、预计量、预计到达、预计可用；数量以引用物料的配置单位保存，不换算。预计批次是该供给的外部模拟批次标识，无需预先创建库存。

预计到达与预计可用分开校验和展示，可用不能早于到达。时间须带 ISO 时区，拒绝无时区及不可能日期。延期记录保留原供给，使用记录时间排序；同一供给记录时点不可重复，调整不得使到达或可用提前。全部已录入模拟记录都参与当前场景，不按计算机当前时间筛选历史。

供给引用必须指向已配置订单及其路线工序和预计供给，数量为正有限数，同一供给全部引用合计不可超过预计数量；供给编号和引用编号分别唯一、物料/批次组合不可重复。不存在物料主数据时也拒绝引用。错误 CSV 不替换表；手动编辑产生的非法数据可保留更正，但会阻止计算。

计算时，对显式引用供给的工序，以调整后的预计可用时点作为最早开始，再满足前序、设备占用和日历窗口。分钟原点仍为 `2026-11-02T08:00:00+08:00`，秒向上取整到分钟。不能进入工作窗口则按既有逻辑显示未排原因。即使预计时间已过，供给仍是条件性，永不转成已确认库存。

条件展示于方案工作台、任务行、保存快照及任务 CSV，包含供给、物料、批次、数量、原预计/生效到达和可用时间以及延期记录。方案保存结构新增 `supplyConditions` 和 `supplyInput`；当前输入变化显示旧快照提示，保存/导出保留原条件。旧方案没有条件元数据时明确要求重算。未排入任务不会生成使用条件。

## 复测样例

在原样例数据上依次导入 `docs/samples/fr011/20_预计到料.csv`、`21_延期模拟记录.csv`、`22_计划供给引用.csv`，再计算。A-MIX 不得早于分钟 180（11:00），不能按到达时点 10:00 提前使用。工作台、任务明细和导出须显示 SUP-001、批次及“条件性供给”。账面库存不增加。清空延期记录后重算，A-MIX 最早为分钟 60（09:00）。在 UI 删除记录可清空表；现有 CSV 导入要求至少一行数据，不支持仅表头清空。

修改预计量为 30、引用数量为负数、改成未知供给/订单/工序、把可用改到到达前或插入重复编号：应显示错误并阻止新排程。导入相同错误 CSV 时应保留原表。
