Compatibility and states
Existing stored status completed/partial mean calculation finished with saved output, not full feasibility. Public outcome=succeeded; partial and supported-check limits remain distinct. queued/running remain active. cancel_requested and stopping (timeout shutdown) are active; terminal cancelled/timed_out only follow termination acknowledgement. Cancellation after a terminal result returns409; repeated in-flight cancellation joins the original stop request. Whichever stop intent is persisted first owns the terminal outcome, including timeout/cancel competition. Late result/progress/error/exit cannot reopen a stopping or terminal run. Duplicate progress does not reset startedAt. Local restart turns nonterminal runs into failed + outcome orphaned with process_interrupted; does not resume them.

History and retry
DurationMs is persisted from run creation to completion, includes queue/stop time. Public active elapsed is server calculated; old terminal duration can be derived from timestamps. Existing frozen executionData.rules, original input version, selection/scope, ruleEvaluationAt and snapshot hash preserve inputs and applicable rule evaluation. Inputs are integrity checked before viewing and retrying.
POST /runs/:id/retry uses existing calculate membership/CSRF/reason/audit. New server UUID, retryOf, trusted actor/request/reason; copies exact frozen input/conditions/revision and reuses original ruleEvaluationAt in Worker. Never adopts request-supplied data/identity/rules. Source run remains unchanged. Active source409; corrupt history409; discarded trial409; changed current execution-facts hash409. Other current input edits do not change a same-input diagnostic replay. Replay creates a draft only; no automatic confirm/release or current-source replacement. Identical data does not promise every future engine build has identical output. Engine executable archival/cross-version execution not implemented.

Chinese UI
Nontechnical status/guidance, elapsed seconds and next action visible; run/input/snapshot/error code/phase, frozen input and detailed check scope in native collapsed details. No invented progress percentage; timeout does not imply infeasibility. Keyboard-expandable details, retry and result links; role/reason guards maintained. Existing broader application copy/other workflow screens were not audited as part of FR038.
