- GET /trials/:id/changes exposes input differences before recalculation, anchored to immutable original plan/run/input/hash. It explicitly does not describe a new calculated result.
- POST /trials/:id/retain requires planner/supervisor, same-origin/CSRF, reason, exact trial revision, own latest recalculated plan with matching current input version and valid original/run provenance. Copied/stale/foreign/discarded results fail closed. Stores independently identified immutable retained comparison/result references and trusted audit identity/time/request/reason. Retain does not adopt, confirm or execute a plan. Later edits/discard preserve retained snapshots and historical result inputs. Discard remains independent and terminates pending Workers.
- UI supports explicit retain, review current input changes, baseline-to-latest comparison and retained result navigation. Generic left/right plan comparison avoids pretending an arbitrary selected plan is the original.
