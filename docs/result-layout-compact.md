## 错误与提醒的统一展示口径

错误：最终未排需求记录、独立检查问题、原计算记录明确severity=error的记录。

提醒：预计迟交需求记录、其他计算过程记录和缺料记录。计算过程记录没有严重级别时按提醒展示，不代表程序异常。按记录计数；同一需求可有多条、不同来源记录不作跨类别去重。两个数字与各自弹窗的逐条记录共用同一份结果模型，错误+提醒等于全部分析记录数。原计算问题、缺料等分项仍可在弹窗切换查看。
