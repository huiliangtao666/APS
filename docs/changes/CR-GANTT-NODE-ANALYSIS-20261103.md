## 实现范围

- 点击已排任务，在原工序链高亮基础上打开非模态悬浮窗。WIP保留及已知停机也按各自节点打开说明，不以整台设备的混合记录替代节点信息。
- 标题可拖动；支持关闭、Escape、点击其他节点切换；任务仍可从高亮摘要重新打开说明，并保留完整明细入口。
- 使用现有设备明细接口的`analysis`区段；经过冻结上下文、查询指纹、资源及节点身份检查。拒绝不匹配查询、不同设备或不在查询范围内的节点。
- 解释固定历时/按量历时、前后工序、开工日日能力与最终投产量、单批上限、班组与实体工装；采用冻结字段，不读取当前维护值冒充历史。
- 投料按节点关联记录展示，附唯一可对应的冻结BOM比例与行号；区分工序总需料和多批供给分配。预览有明确上限，不能跨工序或跨单位相加。
- 问题区区分本节点核对、同需求交付及同需求/在制计算记录；独立检查仅按已保存范围说明。缺失参数快照、实体工装、候选搜索过程和历史日模型精度边界明确显示。
- 修复短任务因边框/内边距撑宽而遮挡相邻节点的点击范围；使用内描边保持时间区间宽度。排程引擎、冻结历史及配置计算规则不变。
