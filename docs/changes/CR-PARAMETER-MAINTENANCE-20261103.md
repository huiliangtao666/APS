# 配置参数工作台逻辑与展示调整

授权来源：用户 2026-11-03 本轮五项要求及四张附图。图示用于组织和交互参考，不导入图中业务值。

## 版本与采用

- 业务数据集仍表示导入业务 Excel 及其关联参数；历史版本、文件原件和冻结运行保留。
- 正式采用的参数 Excel 是配置基线 P1/P2…；候选资料不作为基线。旧数据按已采用参数文件识别，不虚构未导入基线。
- 在线参数、试算覆盖及配置关系维护不增加业务数据版本。当前配置快照单独存储，并保留操作日志；内部修订号用于并发检查。
- 新参数导入才建立新的参数基线。业务数据导入保留其关联参数基线及日志。导入预览期间发生在线维护时，旧预览拒绝确认，防止覆盖修改。
- 已存在的旧版在线修改版本不回退、不删除；旧版没有记录的修改前值和时间不补造。
- 保存后须重新检查本次排程范围。旧检查凭据失效；当前业务查询取得新身份，旧查询分块拒绝混读；已保存运行不变。运行快照只包含采用配置，不携带私人试算修改日志。

## 查询与维护

- 移除旧“主题＋业务领域＋数据层”重复筛选，使用配置对象分类、CP 配置项、该项对象、状态和关键词。
- CP 按编号升序；同一 CP、对象、字段在查看日期只展示当前采用值。B/P/EDIT 历史层不再叠加为主表多行；修改历史单独查看。
- 业务基础值、未维护、只读、待补充也展示；不把空白或目录样例转为运行默认值。
- 全局/规则用清单；物料/SKU、BOM、客户、供应商、设备工装、工序、班组、库区用对象行及适用字段；工厂日历用日期网格。
- 日期对象以实际日期显示。不同参数对象使用各自原子校验、单位、有效期、原来源维护入口；保留原有不可写契约和候选不启用边界。
- 修改冲突保留草稿；核对后重试绑定最新逻辑来源，保留用户输入值和有效期。保存、取消及回查沿用同源入口。

## 适用验证

针对真实保存路由验证：版本不递增、内部修订冲突、权限、持久化重开、修改前后日志、旧预览拒绝、旧就绪凭据拒绝、冻结输入不变、同业务版本查询身份更新。

针对页面验证：CP 排序、来源去重、未维护项、全局和对象表格、日历、取消不写入、并发比较重试、日志和重新打开。浏览器和自动化均使用明确演示数据；任务级结果不等于真实业务 UAT 通过。
