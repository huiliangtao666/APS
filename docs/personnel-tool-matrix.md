## 展示与操作

- 左侧固定一行显示名称、编号、可用数量和窗口关联任务数；班组在前、实体工装在后。任务数按真实任务编号去重，不按日期累加，不含 WIP 物理保留和独立清洗记录。
- 日期格默认显示“并发峰值 / 可用数量”，可切换可用数量或余量。零、未提供、缺失分母和未加载有区别，不将缺失值当零。
- 日历含星期、周末底色；初始高亮冻结观察日（窗口外则定位窗口边界），点击日期可切换高亮，点击日期格进入原有同运行明细。
- 低于 50%、50%～不足 80%、80%～100%、超过 100% 分别着色，超占红色。阈值只用于图形配色，不新增或修改排程约束。
- 一屏总览、紧凑、标准行高；表头和左列固定，内容较少时收紧高度。新版矩阵使用独立栏位偏好键 `E4-matrix-r2`，旧视图偏好不影响新增任务数的默认展示。

原 E4 按日期行分页，100 条可能截断一个资源的日期，也会暂不显示其他资源。新增只读 detail `personnel-matrix` 按完整资源行分页（最多 100 资源 / 180KB），复用原查询的全部逐日值，前端检查冻结身份、查询指纹、资源归属、完整总数和分页推进后显示。图示全部匹配资源，明细继续按日期行分页；未改排程算法、峰值/能力计算、配置或冻结记录。
