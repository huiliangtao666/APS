Implemented behavior
A visible 模拟数据查询 tab works in embedded and standalone layouts. Current main-app categories: products, materials, supplies, supplyDelays, supplyUses, inventory, orders, bom, routes, times, machines, calendars, downtime, dependencies, personnelGroups, rules; plus selected saved-plan tasks.
Each category has a read-only list (50 per page), keyword search, all-field detail and explicit related-record navigation or truthful empty relation text. Product/order filters appear where supported by direct fields or explicit order references. Applicable status fields and date/time/minute ranges are AND-combined. Boundaries inclusive; invalid/blank date values do not match. Clear filters/category changes reset selections and pagination. Rule JSON is presented as readable named parameter values in the query surface.
Relations cover products/orders/routes/times/BOM/tasks, material-to-inventory/expected supplies/BOM/material dependencies, supply-to-delay/use, order-to-tasks/dependencies/uses, operation-to-candidate machines, machine-to-calendar/downtime/tasks, personnel-group dependencies and selected-plan recorded rules. Composite product+operation and resource type namespaces prevent false cross-product/type matches. Rules recorded in a plan do not establish per-task verification success.
Task detail shows original selected-plan times, sources, version/status and same-task findings; a button locates its saved plan/Gantt/problems. Selected Gantt task can open query details and associated inputs. Unscheduled findings may have no task row; full finding list remains on workbench.

Permissions and export
No new identity system, business write endpoint, role or privilege. State/plans still use existing managed-identity protected read APIs. Query users can browse without an operation reason; writes remain prohibited. Query export uses existing /api/export permission, mandatory reason and atomic audit. Body contains selection/filter/revision, never authoritative rows. Server regenerates the same filtered result from current canonical inputs and selected persisted plan. Stale revision=409; unknown table/plan=404; malformed query=400. Explicit member export grant required for query role. CSV preserves fields, original quantities/units/time fields, query revision, selected plan id and Chinese simulation/time-origin labels. Formula-leading text is escaped. Current input relation versus historical task snapshot distinction is visible and exported.
