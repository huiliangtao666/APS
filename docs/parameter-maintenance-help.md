# 参数维护说明

依据：2026-11-03 用户要求逐项说明配置含义、维护方法、0/1含义和影响，并通过感叹号悬浮展示。

## 页面使用

参数数值旁的 `!` 可悬浮查看，也可用键盘 Tab 聚焦或点击打开；Esc 关闭提示。打开另一条说明时，前一条关闭。提示显示在滚动表格和维护窗口外层，避免被表格裁切。

说明包含：含义、影响、如何维护、取值要求、枚举选项、0与1各自含义、空值、当前采用情况以及有效期。列表、对象矩阵、逐日日历、参数草稿及同源结构化维护复用相同说明。

枚举参数改为明确下拉选项。例如资源占用方式选择“独占”“重量共享”或同义的“重量容量共享”，不填写0/1。既有不受支持的值保留显示并提示重选，不静默转换。

## 覆盖与来源

- CP001—CP181均有逐项业务影响说明，含别名CP063→CP074。
- 当前77个原子字段均有专门的含义和0/1说明；数值类型、单位、上下限、整数要求和枚举值读取可执行合同。温度与等待等成对关系另行说明。
- 非原子目录项说明实际维护入口，区分只读来源与规则资料；保存说明或候选值不等于能力已经启用。
- 分钟字段在日模型下明确标注不采用。当前资源占用枚举不会把旧日模型自动切换为共享模型。
- 仓储损耗参考率、客户优先级、每班可用分钟、分钟偏移声明等按实际代码用途说明，不承诺尚未接入的计算效果。
- 空白不等于0、关闭或继承；共享与试算作用范围、最后有效日期的含义一并解释。

说明仅为展示元数据，不写入配置、不新增数据集版本，也不改变排程约束、现有值或历史冻结运行。新增的按需结构化字段说明不会改变原始Excel schema。
