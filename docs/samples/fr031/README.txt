The source example is synthetic. It is NOT proof of actual originalUAT15 mapping or acceptance. A real aggregate source requires an operator's original task/fact mapping, raw cumulative quantity and unit, source description, and 原始分配JSON. Each array object must explicitly contain 记录编号,批次编号,物料编号,数量,单位 as strings. Those records/lots must already exist in the supplied cumulative material table, with matching material/unit, allocated sum exactly matching the original aggregate, and current cumulative values at least each original allocation. No proportional split, inferred lot or physical receipt occurs. Original source/allocation rows are immutable; later cumulative increases are independent versioned corrections, never changes to that original total.

All three tables use full cumulative replacement sets, never event deltas. Reimporting the same accepted set is unchanged (no revision/audit/stock growth). New/conflicting identifiers, deletion of recorded facts, status/output/scrap/consumption regression, overorder usable output and raw unmapped original headers fail closed with diagnostics. Unresolved negative corrections, cancellation/transfer/resume or replacing a mistaken immutable original need a separately approved reconciliation workflow; this implementation preserves the originals and blocks rather than silently changing them.
