4. 歧义、矛盾及需修正
F01（实施前需明确，量化/分摊歧义）：design-bom §4同时给两个生产批各0.104kg、物理粒度0.01及订单汇总0.21再分配，但没有分配明细与合法性条件。若两批均独立实际投料、每批必须0.01整数倍且不能低于0.104，则每批至少0.11，合计至少0.22；不存在总0.21的合法分配。分0.11/0.10虽汇总守恒，后一批少0.004；分0.105/0.105则均违反0.01物理粒度。这不是0.21算错，而是适用业务条件尚未定义。C04-04及checker round_scope只检查汇总值，未验证分配。
修正：区分物理计量与订单汇总记账/采购粒度，说明是否先公共投料再拆批、拆分是否支持更细精度；给出确定残量分配、并列次序、各批精确/分配/量化差额和守恒账。若坚持两批独立物理0.01投料，应明确该例0.21不可直接执行，不能用欠投保持汇总。

F02（实施前需明确，BOM基准×收率×损失组合歧义）：design-bom §2.2仅INPUT且未含收率才反推，而§2.3 TOTAL通式写投入=合格/总收率；未完整定义GOOD_OUTPUT且损失未含、yield_mode=INCLUDED与loss_inclusion=EXPLICIT的合法组合。已有C04-01只覆盖INPUT/TOTAL/损失0；C04-02只有链总乘积，没有中途投料节点；C04-10仅两个布尔值冲突，并未证明这些基准组合可正确计算。参数目录净量加成只说需区分，未给完整枚举和正反例。
修正：给合法组合表及逐物料公式，至少含GOOD_OUTPUT已含收率/损失、另计损失、显式0与空值、INPUT两种损失模式、STAGED中途加入及重复路径拒绝。以同一物理配方不同基准表达应得同量作交叉样例。不能把TOTAL公式无条件套到已含损失的GOOD_OUTPUT定额。

F03（实施前需修正，来源与质量映射组合矛盾）：design-quality §3称预计供给开关关闭时不计入候选，但§2.2仅要求CONDITIONAL分类检查该开关。映射可配置；如果预计来源映射CONFIRMED，现有文案/用例没有来源类型的独立门控，也没禁止这类映射。Test附加探针向checker derive传source_type=EXPECTED、状态可用/CONFIRMED、expected_on=false、60/90、at90，实际返回available=true、conditional=false；source_type未被使用。这与§3的来源开关承诺不一致，且可能丢失预计来源风险。
