流程、状态和线框 r2

1 每步语义
说明i：信息块，只解释；必做*：必要动作/实心按钮；可选○：次级按钮，略过不影响所选合法范围。
已完成✓：绑定动作/版本/时间；阻塞!：原因/影响/解除入口；警告△：允许继续及后果；候选◇：不参与计算。
不适用—：有依据的不使用；未检查?：没有校验结论；尚不支持⛔：实际能力不足，若所选必须则阻塞。
必须有文字/符号，不能只靠颜色。每步突出一个主动作；禁用原因紧贴按钮可见，非hover专有；aria-describedby、错误alert、状态live、可见焦点/键盘返回。只读角色不发写请求。
动作明确“预览（不写有效输入）/确认提交新版本/保存并返回A2/创建运行并冻结输入/导出本运行”。

2 六步主线及门槛
A1 数据准备与范围：先展示双Excel及目标数据集；选择版本、需求/窗口、profile、来源。主动作“检查本次范围”。缺文件/适用配置直接定位对应卡。输入数据四类子表和统一参数页属于此步。
A2 就绪补缺：结构/重复/外键/非法值先按既有全表规则检查，再按所选需求/规则列条件缺口。主动作“重新检查”；修正可编辑记录/参数/映射后返回本步。168CP不是全局必填。
A3 本次配置：支持的规则、dataset/trial、有效日、范围和两文件/overlay摘要；主动作“确认摘要并去计算”。修改使旧就绪过期；本步参数与统一页同源可写。
A4 计算：服务端再次检查身份后冻结。主动作“创建运行并冻结输入”；创建成功后显示真实状态和查看结果动作。空范围不造成功运行。
A5 核对：需求已排/未排和任务数各用自己的分母，真实日轴甘特及问题/来源双向定位，显示检查覆盖。主动作“核对未排与问题”。
A6 保存导出：已有持久化run注明已保存，可重开同runRef；冻结导出/当前数据/参数配置分开。原生保存/复制方案沿兼容原能力，不为workbook造未实现plan保存按钮。主动作“导出本运行”。
兼容分钟模式仍用相同说明/状态语义；保留分钟原点、supported/minimal及B16原显式配置和检查边界，但入口归兼容区。

3 工作台线框
┌排程工作台  [当前数据集 WB-x / vN] [历史运行]──────────────┐
│业务文件 B.xlsx / hash / 已提交；参数 P.xlsx / hash / 采用范围│
│ A1准备 → A2补缺 → A3配置 → A4计算 → A5核对 → A6导出       │
│ A1：[业务Excel：目标/模板/预览/差异/确认]                 │
│     [参数Excel：目标/候选或采用/预览/差异/确认]           │
│     [输入数据子表] [统一配置参数] [CSV兼容与迁移（高级）] │
│ A2：[缺项:对象/字段/行/CP/PA/影响/来源] [去填写]          │
│ A3：[所选范围/日0/规则/scope/有效日/两来源及实际采用值]   │
│ A4：[冻结身份/真实状态/失败原因]                         │
│ A5：runRef固定条；结果 | 日轴甘特 | 问题 | 冻结来源      │
│     [同数据集查询] [同数据集工装维护] [返回原步骤]       │
└A6：重开同运行 / 导出冻结结果；新输入变化仅提示───────────┘
无数据集：业务卡可新建；参数卡禁用并写“请先建立业务数据集”。不是另开输入首页。
查询线框：顶部“工作台>A2>数据查询”，身份“当前vN/冻结run R”；只读表/筛选/关联；维护按钮去同源对象；固定“返回A2（保留选择）”。
工装线框：同一数据集/物理池/CP或映射，数量与单位/共享范围/来源/是否仿真分列；同一编辑器保存；有变化回原步重查。
冻结来源线框：同runRef只读；“修改当前数据另开计算”需显式切换并确认差异，不从旧run直接编辑当前。

4 字段级定位及返回契约
问题字段：issueId、severity/status/blocking、checkedRef、源文件hash/sheet/row/cell、稳定对象键/字段、CP/PA、scope/period、规则、影响需求、责任及依据、locator。
在线定位用稳定业务键而非旧行号；源行作为证据。只读派生显示查看来源；未提交文件结构错误返回原导入卡；无编辑器/无权限/业务待决明确原因与解除人，不造去填写按钮。
returnContext={workspaceView:workbench,datasetRef,step,subview,selectedDemandIds,window,rules,parameterScope,effectiveAt,filters,sort,page,scroll,focus,drafts,selectedRunRef?}。
进入查询/工装前保存上下文；只读往返或取消恢复同一步/选择/筛选/焦点。保存成功以newRef更新当前数据集，保留需求ID/窗口/规则/scope，不静默采用新增需求，回原步重新校验。
所选需求删除/单位变化：显示差异，停止自动继续并要求显式重选；检查未完成显示“已保存，尚未检查”。409保留草稿/三方比较，不自动覆盖。版本变化后不用旧ready。
从冻结结果打开的查询保留runRef，不自动转当前。浏览器刷新重开应恢复同dataset/run身份或清晰说明草稿未保存，不能悄悄换dataset；重开后重新检查。

5 真实状态
queued等待资源；running实际阶段（无真实百分比就不画）；completed已有安排并列实际检查范围；partial已有结果且仍有未排；failed计算未完成并保留冻结输入。
超时不等无解。workbook实际failed+timeout原因时保持实际状态；兼容native有timed_out则映射其真实值。cancel_requested/stopping等待确认，不提前写cancelled。orphaned说明中断未恢复。
运行状态与检查状态分列：通过/冲突/未检查/尚不支持。0任务无需求不标完成；0工装是已知0可能导致未排，与未知分开。
每个视图固定engine/model+runId+inputHash+resultHash；无法匹配则拒绝混合展示。新输入提示更新，旧运行不变。暂未接通Excel甘特时明确“尚未接通，UX-NEW-05/07未完成”，不能用native甘特冒充。
