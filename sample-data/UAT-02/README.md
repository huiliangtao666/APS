# UAT-02 · 工厂日历继承与设备停机

本目录为 APS v0.3 UAT-02 的 R2.1 单线阶段子集。路线、工时、设备、依赖和规则沿用 UAT-01 阶段 CSV；FR-009 订单表沿用原虚构业务值并适配新版字段；增加工厂工作日历与设备停机表，并启用 CALENDAR。所有业务值为虚构测试数据。

导入 APS 预览时按表切换并分别导入：02 工厂工作日历、03 设备资源、04 设备停机例外、10 工艺路线、11 工序工时、12 资源依赖、16 排程规则、17 订单。时间基准为分钟0 = 2026-11-02 08:00（Asia/Shanghai），FC01 工作0–600，MIX02 停机0–15。预期检查：B-MIX 不早于分钟15（08:15），任务不跨工厂非工作段/设备停机。

该样例用于原型核对，不代表 APS 产品 UAT 已执行或通过。字段与测试边界见 `../../docs/APS-TEST-HANDOFF.md` 第5节。
