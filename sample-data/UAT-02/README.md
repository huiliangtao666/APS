本目录为 APS v0.3 UAT-02 的 R2.1 单线阶段子集。路线、工时、设备、依赖和规则沿用 UAT-01 阶段 CSV；FR-009 订单表沿用原虚构业务值并适配新版字段；增加工厂工作日历与设备停机表，并启用 CALENDAR。所有业务值为虚构测试数据。
