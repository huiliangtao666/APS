## 使用顺序

1. 进入对应`UAT-XX`，先读该目录README、`baseline-v0.3/业务操作与边界说明.txt`和`00_导入顺序与阶段说明.csv`。
2. 选择`baseline-v0.3/`中的19类完整输入，或者`baseline-v0.3/本阶段导入数据/`中的阶段子集；二选一，不重复导入。阶段空表表示未启用或没有记录，不表示相关约束已验证。
3. 按当前应用实际支持的字段、规则和阶段选用。UAT-11故意包含错误配置，应验证拦截；不要将其当正常演示输入。UAT-16为后续两产线共享资源场景，数据存在不表示当前应用已支持或授权恢复其开发。
4. 结合候选、参考安排、预期断言及`visuals/`内SVG核对。参考不是唯一排法；候选可故意包含冲突。时间原点为2026-11-02 08:00 +08:00，区间为`[start,end)`。
5. 实际业务验收固定产品SHA、需求版本、启用条件和原始输入，记录实际结果和证据。业务UAT负责人`huiliangtao666`；APS-Test执行，APS-Design协调维护。
